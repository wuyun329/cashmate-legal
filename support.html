三、数据处理说明

全部数据保存在本机：账单、账户、分类、预算、周期记账规则、存钱目标与外观偏好都写入当前设备的本机存储，不经过任何服务器。

应用不联网：应用内不含任何网络请求代码，也不接入广告、统计、推送或崩溃收集类 SDK，飞行模式下功能与联网时完全一致，因此开发者无法读取你的任何账目数据。

卸载即清除：卸载应用（或在设置页执行「清空全部数据」）会删除本机保存的全部数据，且无法撤销、无法找回。请在卸载、更换设备或重置系统前自行导出备份，并另存到设备之外。

四、常见问题

1. 如何备份与恢复？

备份：打开「设置 → 导出备份（JSON）」，应用会生成一个 JSON 备份文件并调起系统分享面板，你把它存到「文件」、iCloud 云盘、网盘或发给自己即可。

恢复：打开「设置 → 从备份恢复（JSON）」，在系统文件选择器里选中之前导出的备份文件。请注意恢复会用该备份覆盖本机现有的全部数据，操作前建议先把当前数据另存一份。

备份包含账单、资金账户、自定义分类、预算设置、周期记账规则、存钱目标与外观设置。两点需要留意：票据照片不随备份导出（换机时需另行保存图片）；应用锁开关不进备份，恢复后需要重新开启。

2. 如何导出 CSV？

打开「设置 → 导出数据（CSV）」，应用会导出当前全部账单为 CSV 文件（文件名形如 bills_20261120_1530.csv），再通过系统分享面板保存到本地或发送出去。

CSV 的列固定为：日期、类型、分类、账户、为谁支付、报销状态、金额、备注，按日期正序排列；转账记录的「分类」列写成「转出账户→转入账户」。导出只读不写，不会改动你的账目。如果你是想把微信 / 支付宝账单拿进应用，请用「设置 → 导入账单（微信 / 支付宝）」。

3. 应用锁忘记密码怎么办？

应用内没有单独的锁密码，开启应用锁后，解锁验证的是你设备自身的 Face ID / 指纹 / 设备密码，应用既不保存也不读取这些信息。

所以「忘记」通常意味着两种情形：一是指纹或面容识别不通过，此时在系统验证界面多次失败后可点「使用设备密码」改用设备密码解锁；二是设备本身未录入生物识别或未设置设备密码，锁屏页会提示你到系统设置里完成设置后再试。

如果连设备密码也已经遗忘，只能按系统提供的方式重置设备，本机数据会随之清除且无法找回，这也正是建议定期导出备份的原因。

4. 换手机如何迁移数据？

分三步：在旧机上「设置 → 导出备份（JSON）」，把备份文件保存到 iCloud 云盘、网盘或电脑等新旧手机都能访问的位置；在新手机安装 CashMate 记账；打开「设置 → 从备份恢复（JSON）」，选中这份备份文件完成恢复。

由于恢复是整体覆盖，建议先在新机上随便记一笔测试，确认账单列表与账户金额都正常后再开始正式使用。票据照片不随备份迁移，需要你自行保留图片；恢复完成后请重新开启应用锁、按需重新填写预算。

注意：不要指望通过卸载重装或系统换机助手直接带走账本数据，卸载会清除本机数据，务必先导出备份。

5. 数据会不会丢失？

应用不设服务器与云同步，数据只有你设备本机这一份，因此以下情况会导致数据不可找回：卸载应用、在设置页执行「清空全部数据」、设备丢失或损坏、系统重装或恢复出厂设置、设备维修时被刷机。

应用本身不会主动删除你的账单（清空操作必须由你手动确认），但开发者没有任何远端副本，数据一旦随设备消失就无法代为恢复。

建议做法：每隔一段时间导出一份 JSON 备份并存到设备之外（云盘 / 电脑），在系统大版本升级、换机、送修前各导出一次；需要长期台账留档时，另外导一份 CSV。
